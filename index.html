Jobizz — Production Career Platform

A complete job discovery and application platform built using Clean Architecture and Flutter BLoC.

Executive Summary

Jobizz is a premium mobile career portal connecting talent with modern tech recruiters. The system utilizes industry-standard best practices in mobile engineering: a domain-driven Clean Architecture structure, robust offline capabilities, secure multi-factor session management, and adaptive layout presentation.

Architecture & State Management

The application relies on Domain-Driven Design (DDD) Clean Architecture separated into three strict layers:

  • Data Layer: Dio client, Retrofit API definitions, local SqfLite storage caches, and Repository implementations.
  • Domain Layer: Pure Dart Entity classes, Value Objects, and isolated Use Case classes enforcing SOLID principles.
  • Presentation Layer: State management powered by BLoC/Cubit to keep the UI entirely reactive, separating business logic from design.

Secure Interceptor Implementation

Here is an abstract showcasing how secure API tokens are managed dynamically using Retrofit & Dio Interceptors on the data layer:

auth_interceptor.dart 
class AuthInterceptor extends Interceptor {
  final SecureStorage _storage;

  AuthInterceptor(this._storage);

  @override
  void onRequest(RequestOptions options, RequestInterceptorHandler handler) async {
    final token = await _storage.read(key: 'jwt_token');
    if (token != null) {
      options.headers['Authorization'] = 'Bearer $token';
    }
    return super.onRequest(options, handler);
  }
}

Wratil — Student & Teacher Quran Ecosystem

A digital ecosystem connecting students with certified Quran teachers using Agora RTC video sessions and Google Gemini AI.

Executive Summary

Wratil is a production-grade educational platform featuring real-time audio/video sessions, automated session booking, integrated digital wallets, and AI-powered learning analytics. It solves the complex engineering challenge of low-latency video stream orchestration and dynamic billing synchronization in cross-platform mobile environments.

Real-time Video Integration (Agora RTC)

The core session feature relies on Agora RTC SDK combined with **Pusher Channels** for signaling and call state tracking. To ensure a professional experience:

  • Call Orchestration: Implemented specialized Cubits tracking token verification, microphone/camera permissions, connection health, and remote peer states.
  • State Synchronization: Real-time alerts are pushed dynamically using Pusher websockets to ensure zero-delay session start notifications.

Agora Room Token Joining Code

Below is a clean snippet showing how dynamic RTC channel tokens are requested and mapped for the Agora engine:

agora_service.dart 
Future<void> joinChannel({
  required String channelName,
  required String token,
  required int uid,
}) async {
  await _engine.joinChannel(
    token: token,
    channelId: channelName,
    uid: uid,
    options: const ChannelMediaOptions(
      clientRoleType: ClientRoleType.clientRoleBroadcaster,
      channelProfile: ChannelProfileType.channelProfileCommunication,
    ),
  );
}
